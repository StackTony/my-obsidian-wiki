# 计算机系统总线与总线标准

一篇面向 PC 硬件的总线科普：从主板与芯片组讲起，先建立"总线是公共通信干线"的模型，再按多个维度分类，最后沿 ISA → PCI → AGP → PCIe 梳理标准演进。它是 [[concepts/linux-driver-model]] 中"物理/虚拟总线"概念的上游硬件背景，也是 [[summaries/linux-pci-subsystem]] 的历史前传。

## 概述

总线（Bus）是计算机各功能部件之间传送信息的**公共通信干线**，由一组导线及相关标准组成。任一时刻通常只有一对设备参与传输，因此需要总线仲裁、地址筛选与定时协议。总线标准把机械结构、功能定义、电气特性固定下来，才让不同厂商的板卡可以互换。

## 核心观点

- **芯片组是 CPU 与外围设备的桥梁**：传统北桥负责 CPU/内存/显卡等高速设备，南桥负责 USB、SATA、PCI、音频、网卡等低速外设；现代 SoC 已把内存控制器与大量外设控制器集成进 CPU，南北桥的界限正在消失。^[inferred]
- **总线可以按四个维度分类**：按连接对象（片内/系统/外部）、按功能（数据/地址/控制/扩展/局部）、按传输方式（并行/串行）、按时钟关系（同步/异步）。同一根总线可以同时落在多个维度里。
- **带宽由频率与位宽共同决定**：`带宽 = 工作频率 × 位宽 / 8`；位宽决定一次能并行传多少位，频率决定每秒传多少次。这是比较 ISA/PCI/PCIe 时最统一的尺子。
- **并行总线受限于同步与信号完整性**：PATA 从 40 线加到 80 线（多出的全是屏蔽地线）才能到 133MB/s；继续提速遇到线长、同步、5V 功耗三重瓶颈，于是转向串行差分。^[inferred]
- **PCIe 用点对点串行取代共享并行**：每个设备独享链路，不需要向整条总线申请带宽；编码从 8b/10b 演进到 128b/130b，把编码开销从 20% 降到约 1.5%。
- **总线标准的价值是兼容性与可扩展性**：统一机械/功能/电气规范后，同一标准的不同厂商模块可以互换，系统升级只需换插件而非重做底板。

## 关键细节

### 总线分类速查

| 维度 | 类别 | 说明 |
|---|---|---|
| 连接对象 | 片内总线 / 系统总线 / 外部总线 | CPU 内部 / 主板功能部件 / 主机与外设 |
| 功能 | 数据总线 DB / 地址总线 AB / 控制总线 CB | DB 双向三态；AB 单向三态；CB 方向由信号决定 |
| 功能 | 扩展总线 / 局部总线 | ISA、PCI 属扩展总线；局部总线用于更高速设备 |
| 传输方式 | 并行 / 串行 | 并行线多、速度快但结构复杂；串行线少、成本低 |
| 时钟关系 | 同步 / 异步 | 同步时钟独立于数据（SPI/I2C）；异步从数据中提取时钟（RS232） |

- 地址总线位数决定可直接寻址空间：n 位地址总线 → `2^n` 字节。
- 数据总线位数通常与 CPU 字长一致；地址/数据总线在部分单片机中复用，PC 中一般分开。

### 常见总线标准与关键数字

| 标准 | 位宽/频率 | 信号线 | 理论带宽 | 备注 |
|---|---|---|---|---|
| ISA | 8/16 位，8MHz | 98 根 | 约 8–16MB/s | 1981 年 PC/XT 起源，1984 年 PC/AT 扩到 16 位 |
| EISA | 32 位，8.33MHz | 198 根 | 33MB/s | 在 ISA 的 98 根上扩 100 根，完全兼容 ISA |
| PCI | 32 位（可扩 64），33MHz | — | 133MB/s（64 位/66MHz 可到 533MB/s） | 1992 年 Intel 提出，独立于 CPU，经桥接与 ISA 共存 |
| AGP | 32 位，66MHz 起，1X–8X | — | 266MB/s–2133MB/s | 显卡专用，仅支持单设备，2002 年后被 PCIe 取代 |
| PCIe 1.0 | 2.5GT/s，8b/10b | 每 Lane 一对差分 | ×16 单向约 4GB/s | 串行点对点，2002 年标准定名 |
| PCIe 2.0 | 5.0GT/s，8b/10b | 同上 | ×16 双向约 16GB/s | 频率翻倍 |
| PCIe 3.0 | 8GT/s，128b/130b | 同上 | ×16 双向约 32GB/s | 编码开销大幅下降 |
| PCIe 4.0 | 16GT/s，128b/130b | 同上 | ×16 约 64GB/s | 2017 年发布 |
| PCIe 5.0 | 32GT/s，128b/130b | 同上 | ×16 约 128GB/s | 2019 年发布，向后兼容 |

> 注：不同资料对 PCIe 带宽的"单向/双向、理论/有效"口径不一致，表中数字按源文表述整理。^[ambiguous]

### 总线标准的三类规范

- **机械结构规范**：模块尺寸、插头、接插件、安装尺寸。
- **功能规范**：每根信号线的名称、功能与工作过程。
- **电气规范**：有效电平、动态转换时间、负载能力。

### 总线结构的优缺点

- **优点**：模块化设计、连线少、易扩展、易升级、便于故障诊断。
- **缺点**：分时共享需要仲裁；带宽有限，重负载设备可能造成延时；每个设备都要做地址筛选；外设与主存之间没有直连通路，必须经 CPU 中转。^[inferred]

### 演进主线

`ISA（1981，8/16 位）→ PCI（1992，32/64 位并行）→ AGP（1997，显卡专用）→ PCIe（2002，串行点对点）`。ISA 胜在兼容与低成本，败在带宽与 CPU 占用；PCI 用桥接把高速设备从 ISA 中分离出来；AGP 只解决显卡带宽，因单设备与高占用被 PCIe 取代；PCIe 用 Lane 聚合（×1/×2/×4/×8/×16）同时覆盖低速网卡与高端显卡，完成扩展接口的大一统。
