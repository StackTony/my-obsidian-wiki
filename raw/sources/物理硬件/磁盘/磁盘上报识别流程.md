#### 磁盘设备上报识别流程：
```
硬件枚举
    │
    ▼
pci_device_probe()                    # PCI 驱动匹配
    │
    ▼
xxx_probe()                           # 存储驱动 probe (ahci_init_one/nvme_probe)
    │
    ▼
控制器初始化 + 设备发现
    │
    ▼
xxx_scan()                            # 扫描设备 (scsi_scan_host/nvme_scan_ns)
    │
    ▼
设备识别          # 获取设备信息
    │
    ▼
块设备注册
    │
    ├── alloc_disk()                   # 分配 gendisk
    ├── 设置容量、队列、操作函数
    └── add_disk()                     # 注册到内核
    │
    ▼
device_add() + kobject_uevent()       # 发送到用户空间
    │
    ▼
用户空间可见: /dev/sda, /sys/block/sda
```
